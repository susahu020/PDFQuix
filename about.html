Why we built this

Most PDF tools online make you sign up, limit your file size, put watermarks on your output, or charge you after a "free trial." We think that's frustrating — especially when you just need to compress one file or merge two documents quickly.

PDFQuick is different. Every tool is completely free, with no account required and no hidden limits. We process everything in your browser using modern JavaScript libraries — so your files never leave your device and we never see your documents.

Technology

PDFQuick is built with vanilla HTML, CSS, and JavaScript — no frameworks, no backend servers. We use these excellent open-source libraries:

  • pdf-lib — create, modify, and save PDF files in the browser
  • pdf.js by Mozilla — render PDF pages to canvas for preview
  • Tesseract.js — OCR engine for extracting text from scanned PDFs
  • PptxGenJS — generate PowerPoint (.pptx) files
  • docx.js — generate Word (.docx) files
  • JSZip — create ZIP archives for batch downloads
  • mammoth.js — parse .docx Word files
