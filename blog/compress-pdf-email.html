Why is my PDF so large?

The most common culprits:

  • High-resolution images — A photo taken on a modern phone is 3–8MB. A PDF with ten such photos is 30–80MB before any compression.
  • Exported from PowerPoint or Word — Office applications embed images at full quality unless you specifically enable PDF compression on export.
  • Scanned documents — Scanners default to 300 DPI for print quality. For screen viewing, 150 DPI is more than sufficient.
  • Embedded fonts — Some apps embed entire font files rather than just the characters used.

Alternative: share via cloud link instead

If your PDF genuinely needs to stay high quality (e.g., for print), skip email attachments entirely:

  • Google Drive: Upload → right-click → Get link → set to "Anyone with link can view".
  • Dropbox: Upload and share a link.
  • WeTransfer: Free transfers up to 2GB, link valid for 7 days.
  • OneDrive: Built into Windows and Microsoft 365.

Prevent large PDFs at export time

Next time you create the PDF, control the size at source:

  • Microsoft Word: File → Save As → PDF → Options → uncheck "Bitmap text when fonts may not be embedded" → check "ISO 19005-1 compliant (PDF/A)" for smaller output, or use "Minimum size (publishing online)" option.
  • Google Docs: File → Download → PDF — unfortunately no compression options. Compress after export.
  • PowerPoint: File → Export → Create PDF/XPS → Options → reduce picture quality.
